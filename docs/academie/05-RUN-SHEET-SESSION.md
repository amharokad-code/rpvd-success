# Déroulé d'une session (1 h 30)

## Avant (T-30 min)
- [ ] Ouvrir la réunion Zoom de la session (créée automatiquement, ou celle collée dans l'admin).
- [ ] Menu Sécurité : « Démarrer la vidéo » décoché, « Réactiver leur micro » décoché, chat privé désactivé, aucun enregistrement. Détails : `docs/legal/02-ZOOM-PROTECTION-ELEVES.md`.
- [ ] Jamais demander une caméra, un nom complet ou un âge. Donner la parole = « Demander de réactiver le micro ».
- [ ] Vérifier dans l'admin (« Participants ») que les liens sont partis (colonne « lien ✓ »). Sinon : « Envoyer les liens maintenant ».
- [ ] Tablette d'écriture + écran partagé prêts. Un deuxième membre de l'équipe modère le chat.
- [ ] La démarche (3-4 étapes) écrite, les 3-4 exercices-pièges prêts du plus simple au plus dur, la fiche des règles d'or.
- [ ] L'outil d'analyse ouvert avec un exercice en photo, pour la démo de fin.

## Minutage

| Min | Bloc | Comment |
|---|---|---|
| 0-15 | **La démarche** | « Aucune théorie aujourd'hui. On apprend la démarche. Écris-la, ne la mémorise pas. » Les 3-4 étapes universelles du chapitre, un mini-exemple par étape. |
| 15-50 | **Les pièges** | 3-4 exercices progressifs calqués sur les pièges types du Ministère. Avant chaque correction, l'élève écrit l'étape suivante dans le chat. Nommer le piège à chaque fois. |
| 50-60 | **La fiche** | Checklist des règles d'or (à faire capturer par les élèves… sur papier). |
| 60-88 | **Questions** | Le modérateur trie le chat. Toujours répondre par la démarche, jamais par la réponse seule. |
| 88-90 | **Passerelle** | Démo en direct : photo d'un exercice → pattern en 3 niveaux. Dire les vrais prix (Basic 12 $ / Pro 20 $ aux 3 mois, résiliable). Le lien arrive aussi par courriel demain matin. Fermer la réunion. |

## Script de passerelle (60 s)
« Ce que vous venez de faire, l'outil RPVD le fait pour n'importe quel exercice, à n'importe quelle heure. Je prends une photo… voilà le pattern, puis avec vos chiffres, puis étape par étape. Vous recevez le lien demain matin. Et si un autre examen arrive : votez lundi, et dimanche prochain c'est peut-être votre sujet. »

## Après
- Rien à envoyer : le courriel de suivi part seul lundi 9 h.
- Noter les questions qui reviennent : ce sont les sujets des prochaines pubs.

## Gabarits de démarche (exemples)

- **Stœchiométrie (Sec 4)** : 1. Équation balancée. 2. Masse → moles (n = m / M). 3. Rapport des coefficients. 4. Moles → masse demandée.
- **Participe passé (français)** : 1. Auxiliaire ? 2. Avec être → accord avec le sujet. 3. Avec avoir → COD placé avant ? 4. Pronominal → cas particuliers.
- **Justifier en lecture** : Affirmation (je réponds) + Preuve (citation entre guillemets, ligne) + Explication (le lien entre les deux).

# Zoom : protéger les élèves (mineurs)

Les réunions créées automatiquement ont déjà : inscription obligatoire, lien personnel (un appareil à la fois), caméras des participants coupées, micros coupés à l'entrée, mode focus (les élèves ne voient que l'animateur), aucun enregistrement automatique. Les réglages ci-dessous verrouillent le reste au niveau du compte. **À faire une fois** sur zoom.us → Paramètres.

## Compte (Paramètres → Réunion)

| Réglage | Valeur |
|---|---|
| Vidéo des participants | Désactivée |
| Couper le micro des participants à l'entrée | Activé |
| Autoriser les participants à réactiver leur micro | **Désactivé** (l'animateur clique « Demander de réactiver ») |
| Chat | Activé |
| Chat privé (entre participants) | **Désactivé** |
| Les participants peuvent discuter avec | Tout le monde publiquement (ou Animateurs seulement) |
| Partage d'écran | Animateur seulement |
| Annotation par les participants | Désactivée |
| Tableau blanc des participants | Désactivé |
| Autoriser les participants à se renommer | Activé (prénom ou pseudonyme) |
| Masquer les photos de profil des participants | Activé |
| Enregistrement local par les participants | **Désactivé** |
| Enregistrement infonuagique | Désactivé |
| Transfert de fichiers | Désactivé |
| Mode focus | Activé (autoriser) |
| Retirer un participant / ne pas autoriser le retour | Activé |

## Pendant le cours (menu Sécurité de l'animateur)
- Vérifier : « Démarrer la vidéo » décoché, « Réactiver leur micro » décoché, « Discuter » coché.
- Donner la parole : participant → « Demander de réactiver le micro ». L'élève accepte, parle, puis « Couper le micro ».
- Problème de comportement : « Retirer » (l'élève ne peut pas revenir avec le même lien).
- Ne jamais demander à un élève d'allumer sa caméra ni son nom complet.
- Ne jamais enregistrer la session (aucun consentement n'a été demandé pour ça).

## Si un élève partage ses coordonnées dans le chat
Supprimer le message (survol → Supprimer), rappeler la règle à tout le monde sans nommer l'élève.
